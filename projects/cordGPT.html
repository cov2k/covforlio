cordGPT

make your discord bot understand you more effectively

overview

cordGPT is an api-first RAG system that lets discord bots populate a vector database with chat messages, vod transcripts, and metadata. the bot becomes a thin client, while the api handles ingestion, chunking, embedding, and storage. great for livestreamers.

architecture

discord bot → ingestion api → vector db → retrieval layer
