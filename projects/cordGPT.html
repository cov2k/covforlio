cordGPT

make your discord bot understand you more effectively

overview

cordGPT is an api-first RAG system that lets discord bots populate a vector database with chat messages, vod transcripts, and metadata. the bot becomes a thin client, while the api handles ingestion, chunking, embedding, and storage. great for livestreamers.

architecture

discord bot → ingestion api → vector db → retrieval layer

api reference

base url: http://localhost:8000

POST /retrieval/embed

generate an embedding vector for a given text input.

request:
{
  "text": "hello world"
}

response:
{
  "embedding": [...]
}

POST /retrieval/store

store text + its embedding in the faiss index.

request:
{
  "text": "some message"
}

response:
{
  "data_stored": "some message"
}

POST /retrieval/search

retrieve the top-k most similar stored chunks.

request:
{
  "query": "why is my stream lagging?",
  "k": 3
}

response:
{
  "results": [...]
}

POST /retrieval/query

perform full retrieval-augmented generation.

request:
{
  "query": "explain my stream lag"
}

response:
{
  "context_used": "...",
  "response": "..."
}
