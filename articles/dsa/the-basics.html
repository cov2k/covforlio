data structures & algorithms basics

a high-level overview of core data structures

arrays

an array is a collection of elements stored in contiguous memory. fast random access, predictable performance, but resizing is expensive.

py example


arr = [1, 2, 3, 4]
print(arr)
print(arr[2])

c++ example


#include 
using namespace std;

int main() {
    int arr[4] = {1, 2, 3, 4};
    cout << arr[0] << endl;
    cout << arr[2] << endl;
}

1

3

efficiency

  • access: O(1)
  • update: O(1)
  • insert/delete at end: O(1)
  • insert/delete in middle: O(n)

nodes connected by pointers.

stacks & queues

stacks: last-in, first-out. queues: first-in, first-out.

trees

why these matter

every algorithm you write sits on top of a data structure. choosing the right one means faster code, fewer bugs, and cleaner logic.
