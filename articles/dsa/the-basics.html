why array access is O(1)

        

            arrays store their elements in contiguous memory. this means that if you know the starting
            address of the array, you can compute the location of any element instantly using:
        

        
        address_of_element = base_address + (index * size_of_each_element)
        

    




    
linked lists

    

        nodes connected by pointers.
    


    
python example (interactive)


    

    

    


    
why linked list access is O(n)

    

        linked lists do not store elements in contiguous memory. each node only knows where the
        next node is. to reach the n-th element, you must start at the head and follow each pointer
        one by one until you arrive at the correct node.
    


    
node_i = head
for step in range(n):
    node_i = node_i.next
    


    

        this traversal grows linearly with the index. accessing the first element is O(1), but
        accessing the last element requires visiting every node, making linked list access O(n).
